### 🧪 Featured Security Labs & Projects

- **🏢 D.A Security — Multi-Cloud Enterprise Simulation Lab**
  - Architected a multi-account **AWS Organizations** environment (`Management`, `Audit`, `Workload-Prod`, `Sandbox` OUs) governed by **Service Control Policies (SCPs)** and **Tag Policies**.
  - Federated identity with **Microsoft Entra ID & M365 E5** using **SAML SSO**, **Conditional Access MFA**, and **Privileged Identity Management (PIM)**, ingesting telemetry into **Microsoft Sentinel** to simulate and detect identity and endpoint attacks.
- **🤖 AI Data Loss Prevention (DLP) Scanner**
  - Built an inspection pipeline to detect and prevent sensitive data leakage in LLM prompts and AI gateway workflows.
- **⚡ Automated Cloud Remediation & Guardrails**
  - Designed event-driven remediation workflows using **AWS Config** and **GuardDuty**—prioritizing non-destructive containment (such as disabling rather than deleting compromised IAM keys) to protect production availability.
- **🔍 Defending Azure & Threat Hunting Walkthroughs**
  - Hands-on detection and incident response labs covering Windows endpoint telemetry, identity compromise scenarios, and SIEM rule tuning.
